# RL-Notes

This repository contains my notes on Reinforcement Learning (RL). 
The notes are organized into different sections covering various topics in RL, including foundations, concepts, algorithms, and practical implementations.

## Documentation site

Dependencies are managed with [uv](https://docs.astral.sh/uv/). Python packages install into `.venv` in this repo (not your global conda base).

```bash
uv run --group docs mkdocs serve
```

Open [http://127.0.0.1:8000/](http://127.0.0.1:8000/). To build static files: `uv run --group docs mkdocs build`.
