# RL Notes

Living notes on reinforcement learning: ideas, equations, algorithms, and
implementation lessons.

## Learning path

1. [Foundations](foundations/index.md): MDPs, returns, Bellman equations, and
   dynamic programming.
2. [Policy optimization](policy-optimization/index.md): policy gradients,
   variance reduction, stable policy updates, and
   [actor-critic methods](policy-optimization/actor-critic/index.md), including
   A2C, A3C, TRPO, PPO, and SAC.
3. [Q-learning](q-learning/index.md): value-based control, from tabular
   Q-learning to DQN.
4. [Advanced topics](advanced/index.md): model-based, offline, and safe RL.
5. [Practice](practice/index.md): experiments and implementation lessons.
