# RL Notes

Living notes on reinforcement learning: ideas, equations, algorithms, and
implementation lessons.

## Learning path

1. [Foundations](foundations/index.md): MDPs, returns, Bellman equations, and
   dynamic programming.
2. [Policy optimization](policy-optimization/index.md): policy gradients,
   variance reduction, actor-critic foundations, and stable policy updates such
   as A2C, A3C, TRPO, and PPO.
3. [Q-learning](q-learning/index.md): value-based control, from tabular
   Q-learning to DQN.
4. [Actor-critic](actor-critic/sac.md): methods that combine an explicit actor
   with a learned critic. SAC currently connects policy optimization with
   Q-learning.
5. [Advanced topics](advanced/index.md): model-based, offline, and safe RL.
6. [Practice](practice/index.md): experiments and implementation lessons.
